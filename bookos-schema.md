# BookOS output schema

Use this reference selectively. Preserve headings in Markdown deliverables so notes can be indexed consistently.

## Deep decomposition

1. **One-sentence thesis** — the claim the user should remember.
2. **Logic map** — the causal or narrative structure connecting the main ideas.
3. **Core models** — five to ten entries with:
   - model name;
   - mechanism;
   - supporting example or evidence;
   - boundary or failure condition;
   - transferable application.
4. **Human patterns** — recurring motives, incentives, biases, power dynamics, or relationship patterns.
5. **Applications** — only the domains relevant to the user.
6. **Skeptical reading** — weak evidence, hidden assumptions, contradictions, or context limits.
7. **Action principles** — decisions or behaviors written as specific rules.
8. **Insight cards** — atomic cards using the format below.
9. **Review questions** — questions that require recall and application rather than recognition.
10. **What to remember** — three to five durable ideas.

## Atomic insight card

```markdown
### Insight: <short name>

- Claim:
- Mechanism:
- Evidence or example:
- Boundary:
- Application:
- Tags: #topic #domain #behavior
```

Keep one idea per card. A card must remain understandable outside the original book summary.

## Action principle

```markdown
### Principle: <decision rule>

- Trigger: When does this apply?
- Action: What should be done?
- Why: Which mechanism supports it?
- Check: How will the user know it worked?
```

Avoid actions such as “think more” or “be disciplined.” Prefer observable behavior.

## Review questions

Include a mix of:

- recall: What is the model?
- mechanism: Why does it work?
- discrimination: When does it not apply?
- transfer: How would it change a real decision?
- critique: What evidence would falsify it?

## Content derivative

```markdown
# Working title

## Hook

## Changed judgment

## Example

## Practical takeaway

## Closing question
```

Never fabricate a first-person story, result, or emotional reaction for the user.
